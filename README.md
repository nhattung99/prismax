# PrismaX Learn — Knowledge & Documentation Hub

An interactive, 100% English single-view educational and documentation hub for the **PrismaX** (`prismax.ai`) ecosystem — the service layer for physical AI.

---

## 🌟 Modules

### 1. 📚 Onboarding 101
12 core interactive concept cards with category filtering, source citations, and slide-over detail drawers:
- What is PrismaX?
- Three Pillars: Robots — Data — Intelligence
- VLA (Vision-Language-Action)
- VLA Foundry
- Teleoperation (Teleop)
- Verify Quality
- The First 100
- Prisma Points
- $PIX Token
- Gateway (`gateway.prismax.ai`)
- Robot Fleet (Piper, TOK2, YAM)
- Membership Tiers (Amplifier & Innovator)

### 2. 📖 Network Glossary (A–Z Dictionary)
Instant searchable dictionary of 19 official network terms, roles, token clearing mechanics, and hardware standards with category filtering.

### 3. ⚡ How Teleop Works
Interactive 9-step workflow diagram tracing data from physical robot arm operation to community quality verification, consensus scoring, and VLA model feedback loops.

### 4. 🌐 Ecosystem Map
Filterable network directory categorized into 4 sectors:
- **Lead Backers**: a16z crypto CSX ($11M lead investor)
- **Day 1 Launch Partners**: Monad, Peaq, Sentient, Virtuals Protocol, OpenMind, Perle Labs, Stanford Blockchain Accelerator, XMAQUINA, Zeno, ChainGPT, Blockchain Builders Fund
- **Device Partners**: Agilex Robotics (Piper), Airbot (TOK2), I2RT Robotics (YAM), Realman
- **Platform Products**: Gateway, App Platform, Verify Quality, VLA Foundry, Robot Fleet

### 5. 🗓️ Timeline & Roadmap
Chronological record of verified public disclosures from June 2025 to July 2026.

## 🚀 Quick Start (Local Development)

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev
```

Open [http://localhost:5174](http://localhost:5174) in your browser.

---

## 🛠️ Build & Verification

```bash
npm run build
```

Production bundle is generated in `dist/`.
